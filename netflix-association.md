# Netflix Genre Association Analysis

**Tools:** R, RStudio, arules, Apriori association-rule mining, visualization.

Using 8,807 Netflix titles, this project splits multi-genre labels into transactions and applies Apriori to explore which genres appear together. Selected association-rule lifts include International/Korean TV Shows → Romantic TV Shows (~12.1), TV Mysteries → TV Dramas (~7.3), and Horror Movies → Thrillers (~5.39).

**Interpretation note:** These are associations between catalog genre labels, not evidence of what individual viewers like or watch together.

Original presentation, analysis report, and R Markdown source may be added to this project later.
